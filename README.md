## 📌 Overview

**AWS Resource Tracker & GitHub API Integration** is a Linux-based automation project that combines **Bash scripting, AWS CLI, GitHub REST API, cURL, and jq** to simplify routine cloud-resource auditing and repository access checks.

The project was developed as a practical Cloud Support / Linux Support automation exercise.

Instead of manually checking multiple AWS services and GitHub repository access information, the project provides shell scripts that perform these checks from the Linux command line.

### 🎯 Main Objective

The project demonstrates a practical support-automation workflow:

```text
Manual Checking
      ↓
Linux / Bash Automation
      ↓
AWS CLI Integration
      ↓
AWS Resource Auditing
      ↓
REST API Integration
      ↓
Authentication & Validation
      ↓
Error Handling
      ↓
Reports & Logs
